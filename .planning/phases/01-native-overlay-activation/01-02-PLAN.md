<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| user settings → shortcut registry | Untrusted shortcut strings are converted into OS registrations |
| shortcut callback → controller | OS events invoke global state transitions while another app is focused |
| controller → AppKit/Win32 adapter | Mode changes alter focus and pointer hit testing at the native boundary |
| Rust events → React badge | Native state is reflected in a webview UI layer that must not control native handles |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-05 | Tampering | shortcut configuration | high | mitigate | Parse only supported accelerator tokens, validate each action separately, and commit a candidate registry only after every registration succeeds; otherwise roll back. |
| T-01-06 | Denial of service | click-through transition | high | mitigate | Serialize and make mode transitions idempotent, flush pointer capture before pass-through, and keep Esc registered independently of native hit testing. |
| T-01-07 | Spoofing | mode badge/events | medium | mitigate | Render only typed events from the Rust controller and keep the UI badge informational; React cannot invoke arbitrary native window operations. |
| T-01-08 | Tampering | platform window flags | medium | mitigate | Centralize AppKit/Win32 changes behind `PlatformWindowAdapter` and unit-test the desired styles/hit-test results per target. |
</threat_model>
