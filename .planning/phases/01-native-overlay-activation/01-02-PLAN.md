<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tray/global shortcut → Rust lifecycle | OS/user commands cross into native visibility control |
| Rust → AppKit/Win32 window manager | Transparency, z-order, focus, and display bounds cross the native boundary |
| capability file → webview commands | Tauri permissions determine which frontend actions are exposed |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-03 | Elevation of privilege | Tauri capabilities | high | mitigate | Scope capabilities to the overlay, tray, events, and global shortcuts; do not grant filesystem, network, capture, or shell access. |
| T-01-04 | Spoofing | global toggle | medium | mitigate | Route callbacks through the native controller and emit typed mode state rather than allowing arbitrary frontend window commands. |
| T-01-05 | Tampering | macOS private transparency | medium | mitigate | Record `macOSPrivateApi` and the direct signed/notarized distribution constraint in the support evidence before release packaging. |
</threat_model>
