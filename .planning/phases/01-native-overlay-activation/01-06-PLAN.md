## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| native OS failure → Rust error model | Permissions and window failures become app state |
| Rust error event → React badge | Actionable recovery payloads cross IPC |
| error action → native command | User action invokes a constrained retry or settings command |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-15 | Denial of service | initialization retry | high | mitigate | Fail closed to Hidden, preserve scene/controller, debounce retry, and keep the process alive. |
| T-01-16 | Tampering | error action IPC | medium | mitigate | Accept only the typed action issued for the current error code; reject unrelated actions. |
| T-01-17 | Information disclosure | error detail | low | accept | Report platform codes and recovery steps without screen pixels, credentials, or unrestricted paths. |
</threat_model>
