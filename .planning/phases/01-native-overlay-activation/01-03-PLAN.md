## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| OS permission/error state → Rust error model | Native failures and permission changes become user-visible recovery state |
| Rust error events → React notification | Error payloads cross IPC into a non-modal UI with actionable commands |
| WebDriver runner → built application | Automated tests drive a desktop process and its lifecycle |
| npm registry → test toolchain | WebDriver packages enter the development and CI environment |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09 | Denial of service | overlay initialization/retry | high | mitigate | Fail closed to Hidden, preserve scene/controller, debounce Retry, and keep the process alive rather than retrying indefinitely. |
| T-01-10 | Tampering | error action IPC | medium | mitigate | Use typed action enums and allow Retry/Open System Settings only for the error code that issued them. |
| T-01-11 | Information disclosure | support matrix and logs | low | accept | Record platform behavior and error codes without screen pixels, user content, credentials, or unrestricted paths. |
| T-01-12 | Tampering | WebDriver dependencies | high | mitigate | Pass the blocking npm legitimacy checkpoint for every SUS package and pin approved versions in the lockfile. |
</threat_model>
