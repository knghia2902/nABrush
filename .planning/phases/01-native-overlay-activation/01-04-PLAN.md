<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| settings webview → shortcut registry | User-provided accelerators become OS registrations |
| settings webview → startup adapter | A local preference changes launch-at-login registration |
| global shortcut service → controller | OS callbacks cause mode transitions while another app is focused |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-09 | Tampering | shortcut IPC | high | mitigate | Parse a constrained accelerator grammar, validate each action, and commit candidates only after all registrations succeed. |
| T-01-10 | Denial of service | conflict rollback | high | mitigate | Preserve the complete last working set and return a suggested alternative when registration fails. |
| T-01-11 | Elevation of privilege | startup adapter | medium | mitigate | Expose only a typed boolean command and perform platform registration on explicit opt-in; no arbitrary startup command or path is accepted. |
</threat_model>
