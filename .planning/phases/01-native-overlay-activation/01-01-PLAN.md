<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| tray/webview → Rust controller | UI actions and events cross the Tauri IPC boundary into lifecycle and window operations |
| global shortcut service → controller | OS-delivered key events trigger visibility changes while another application is focused |
| Rust process → native window manager | Window flags, display bounds, transparency, focus, and hit testing cross into AppKit/Win32 through Tauri |
| package registry → build workspace | Dependencies enter the executable and build toolchain during scaffold installation |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-01-01 | Tampering | Tauri IPC commands | medium | mitigate | Use an explicit capability file and typed command payloads; reject unknown mode transitions in the Rust controller. |
| T-01-02 | Spoofing | global shortcut callback | medium | mitigate | Register only the configured command bindings and route every callback through the Rust-owned controller state. |
| T-01-03 | Elevation of privilege | transparent overlay/native window | high | mitigate | Keep native window handles and platform flags in Rust, use the minimum Tauri permissions, and never expose arbitrary shell or filesystem commands to the webview. |
| T-01-04 | Tampering | package installs | high | mitigate | Pass the blocking npm legitimacy checkpoint before installing every SUS package and pin the approved versions in pnpm-lock.yaml. |
</threat_model>
