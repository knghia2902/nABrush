<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Webview pointer/toolbar -> React state | Pointer samples, style controls and tool selection are untrusted browser input. |
| React `invoke` -> Rust SceneStore | Typed scene payload crosses the Tauri command boundary and must be revalidated natively. |
| Native SceneStore -> every overlay webview | Whole snapshots are broadcast to multiple display viewports; one client must not create a divergent document. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01-01 | Tampering/Denial of Service | `commit_scene_item` / `SceneStore::commit_scene_item` | high | mitigate | Typed serde payload, unknown-field rejection, finite/range/length limits, legacy normalization only for the known stroke shape, and no mutation on rejection. |
| T-03-01-02 | Tampering | Scene item IDs and snapshot mutation | medium | mitigate | Bounded non-empty IDs, duplicate/replayed IDs return the existing whole snapshot and never append a second item. |
| T-03-01-03 | Tampering | Canvas text/scene rendering boundary | medium | mitigate | Retained text is data in the typed scene model; renderer consumes semantic fields through Canvas APIs and never treats scene data as executable markup. |
| T-03-01-04 | Tampering | Toolbar/popover/native click-through | high | mitigate | Chrome is sibling DOM with `data-scene-excluded`, explicit interactive descendants only, and native `set_ignore_cursor_events` remains the pointer authority. |
| T-03-01-05 | Tampering | Realtime preview and retained scene | medium | mitigate | Transient candidate is separate React state, commit occurs once after valid pointer-up, and cancel/mode/focus abort clears it without native mutation. |
| T-03-SC | Tampering | Package-manager install surface | low | accept | No npm or crate installation is planned for this phase, so no new package trust boundary is opened. |
</threat_model>
