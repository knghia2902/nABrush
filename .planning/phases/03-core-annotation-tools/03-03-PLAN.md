<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Keyboard/text editor -> React draft | IME and keyboard input are untrusted; draft remains transient until an explicit valid commit. |
| React text/erase invoke -> Rust SceneStore | Text payload and erase ID cross the Tauri IPC boundary and are revalidated natively. |
| Canonical scene -> renderer hit-test/native mutation | Hover target selection must be deterministic and only one selected ID may cross into erase mutation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-03-01 | Tampering/Denial of Service | text payload and draft commit | high | mitigate | Bound text size/line count at Rust validation, keep text as Canvas data, ignore composing Enter, and reject invalid payloads before mutation. |
| T-03-03-02 | Tampering | duplicate/replayed text or erase IDs | medium | mitigate | Preserve bounded ID dedupe for commits and validate erase IDs; repeated erase of a removed ID is a broadcast no-op. |
| T-03-03-03 | Tampering | committed text renderer | medium | mitigate | Render scene strings only through Canvas `fillText`/measured lines; the DOM editor is transient and scene-excluded. |
| T-03-03-04 | Tampering | eraser targeting | high | mitigate | Reverse-order type-specific hit-test returns one topmost ID, pointer move is read-only hover, and native mutation removes at most one matching ID. |
| T-03-03-05 | Denial of Service/Tampering | toolbar, draft and click-through surfaces | high | mitigate | Explicit chrome pointer events only in interactive mode, scene-excluded markers, no capture for eraser, and native click-through remains authoritative. |
| T-03-SC | Tampering | Package-manager install surface | low | accept | No package installation occurs; existing dependencies remain the only install surface. |
</threat_model>
