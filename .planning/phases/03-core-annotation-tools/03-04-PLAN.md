| Overlay WebView -> Tauri commands | Smoke tests invoke the same native scene commit/erase and mode boundaries as production UI. |
| macOS/Windows host -> test evidence | Native windowing, click-through and multi-display behavior vary by host and require separate evidence. |

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-04-01 | Tampering/Denial of Service | E2E scene payload path | high | mitigate | Suite asserts normal typed commit/erase path, bounded snapshot count and no transient/chrome item leakage; native tests remain the trusted validation gate. |
| T-03-04-02 | Tampering | duplicate/replayed IDs | medium | mitigate | Scene assertions compare stable IDs/counts and the native dedupe tests are required in the validation map. |
| T-03-04-03 | Tampering | text rendered as UI markup | medium | mitigate | E2E checks draft/editor lifecycle and scene-excluded marker while unit tests verify Canvas text rendering data path. |
| T-03-04-04 | Tampering | eraser one-item targeting | high | mitigate | Smoke test hovers/clicks one target and checks a one-item count delta; native exactly-one tests are required before suite acceptance. |
| T-03-04-05 | Denial of Service/Tampering | toolbar/click-through pointer interception | high | mitigate | Suite checks global mode, toolbar exclusion and computed pointer-events; manual matrix verifies native underlying-app input on both OSes. |
