<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Canvas pointer events -> geometry helpers | Raw pointer coordinates and drag sizes are untrusted and must be canonicalized and bounded. |
| React scene item -> Rust typed command | Geometry/style data crosses the Tauri IPC boundary and is validated again in Rust. |
| Retained SceneStore -> multiple Canvas viewports | One canonical shape must be rendered consistently without per-display mutation. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-02-01 | Tampering/Denial of Service | line/arrow/shape payloads | high | mitigate | Typed discriminator, `deny_unknown_fields`-equivalent validation, finite/range bounds, point/item limits, and reject-before-mutate in `SceneStore`. |
| T-03-02-02 | Tampering | duplicate/replayed geometry IDs | medium | mitigate | Stable bounded IDs and existing SceneStore dedupe return the original snapshot instead of appending a second item. |
| T-03-02-03 | Tampering | Canvas text data path | medium | mitigate | Keep future text fields as data in SceneItem and retain the renderer rule that scene strings are drawn through Canvas APIs, never interpreted as markup. |
| T-03-02-04 | Tampering/Denial of Service | eraser/geometry pointer interception | high | mitigate | Geometry gestures are scoped to the captured pointer; toolbar remains scene-excluded and native click-through authority is unchanged. |
| T-03-02-05 | Tampering | short drag and transient state | medium | mitigate | Apply the 4px logical threshold before mutation, clear transient candidates on abort, and never bulk-mutate from pointer move. |
| T-03-SC | Tampering | Package-manager install surface | low | accept | No npm or crate installation is planned; existing locked dependencies are reused. |
</threat_model>
