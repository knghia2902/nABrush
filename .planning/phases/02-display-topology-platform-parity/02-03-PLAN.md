<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native serialized viewport/scene event → React state | Native geometry and scene payloads determine what each webview renders. |
| React scene commit command → Rust SceneStore | Pointer-derived payloads cross from an untrusted webview into shared native state. |
| CSS renderer → native hit-testing | Browser pointer feedback must not override native click-through behavior. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-10 | Tampering | scene commit bridge | high | mitigate | Route commits through the typed Tauri command, validate IDs/finite points in Rust, and consume one native SceneStore event in all webviews. |
| T-02-11 | Tampering | viewport transform payload | high | mitigate | Validate descriptor dimensions/scale before use, clamp pointer conversion to the logical viewport, and test rotation/negative-origin cases. |
| T-02-12 | Spoofing | mode/error badge state | medium | mitigate | Drive badges from typed native mode/error events, keep `data-scene-excluded` markers, and never let renderer copy replace native status state. |
| T-02-13 | Denial of service | long error copy/layout | low | mitigate | Bound badge layout, wrap text within the viewport, and keep actions keyboard reachable without resizing native windows. |
</threat_model>
