<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Native display snapshot → Rust topology model | OS-reported identity, geometry, scale, and rotation enter the application state. |
| Rust viewport event → React renderer | Serialized native geometry controls canvas sizing and coordinate transforms. |
| Renderer pointer samples → retained scene contract | Untrusted webview coordinates are converted into canonical desktop points. |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-02-01 | Tampering | `DisplayDescriptor` validation | high | mitigate | Reject non-finite, zero, negative, or out-of-range geometry and scale before it reaches controller/native calls; test invalid fixtures. |
| T-02-02 | Elevation of privilege | viewport event and renderer bridge | medium | mitigate | Emit viewport metadata only from the Rust controller, generate identities in Rust, and keep CSS pointer-events subordinate to native hit-testing. |
| T-02-03 | Denial of service | topology coalescer | high | mitigate | Bound the debounce input, cancel stale work, and apply one final validated snapshot to prevent event bursts from creating unbounded reconciliation work. |
| T-02-04 | Tampering | canonical scene coordinates | medium | mitigate | Use the typed viewport transform for both drawing and pointer conversion, retain native origins, and cover rotation/scale/negative-origin cases with direct tests. |
</threat_model>
